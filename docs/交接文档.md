## 四、我的交易执行规范（**必须严格照做**）

### 资金与仓位
- 测试本金 **1000 USDT**；**单笔固定 300 U × 3 倍杠杆**（**忽略博主自己说的倍数/风险百分比**）；
- **最多同时 3 笔**（300×3=900U）。

### 开仓
- 博主给了**加仓价**（如 DCA 0.02）→ ①**头仓 1/3（100U）**按入场价进；②**加仓 2/3（200U）**在加仓价进；
- 博主**没给加仓价** → **一次性 300U** 按点位/现价进；
- **开仓门槛**：博主给的价格 vs 交易所现价 **必须在 ±1% 内**才开；超出则**等待**（最多 30 分钟），等到价格进入 ±1% 再开，始终不进就不开；
- **"现价单"（CMP/市价）**：直接按当时市价进，不设门槛；
- 价格精度：小数过多时**取整**（如 0.02454 → 0.02455）；
- 开仓同时**挂好止损与止盈**。

### 止盈止损（多档）
- **单一日标止盈** → 到价**全部平仓**；
- **多档止盈** → **每档平 1/3**（TP1/TP2/TP3）；
- **到 TP1 后：把止损移到开仓价（保本）**；到 TP2 **止损仍保持开仓价**；到 TP3 **全部平仓**；
- 博主**临时说提前止盈/止损/撤单**（如"行情疲软先走"）→ **不管当前价格，立即全部平仓**；
- 博主说"**移动止损到 X**" → 改止损单到 X；说"**带成本防守**" → 止损移到开仓价；
- 博主说"**止盈一半/减仓**" → 按比例平仓。

### 回测口径（重要）
- 用**币安真实 1 分钟 K 线**；
- **必须计入真实响应延迟**：实测**解析约 12 秒** + 币安下单接口约 1 秒 + 轮询间隔 → **整体约 15~35 秒**（**我之前错说成 3 秒，已纠正**）；
- 图表上的止盈止损点位**必须读图**（文字常只写"止盈在上方"）。

## 五、现在的缺陷（**新对话必须先解决这些**）

1. **❗数据抓取不可靠（最致命）**
   - 历史上"滚动翻页抓群历史"的做法会**切碎/合并消息、丢失内容**（例：风寻的 `robo 0.037空`、`fogo 0.079头仓空` **整条没抓到**）；
   - **时间戳被侧边栏污染**（所有信号日期变成同一个 Sep 8）→ 导致回测的"实际成交价"全错；
   - **结论：不要再信任旧的滚动抓取数据**，历史数据要么重抓（消息级 1:1），要么用我的截图。

2. **❗图片（图表）解析未打通**
   - UA 这类博主**止盈画在 K 线图上**，文字只有"止盈在上方"；
   - 已验证 **DeepSeek 视觉模型能准确读截图并诚实报"看不清"**（不编造）；
   - 但**服务器浏览器抓不到群里的图**（抓到的是图标）；
   - **最稳方案：我在自己飞书里滚动截图（5~8 张/群）发给 AI，用视觉模型逐张读点位** —— 这条路已验证可行，应优先采用。

3. **❗解析偶发认错**
   - 冷门币被 LLM 猜错（例：`zama` 被解析成 `XRP`）；
   - **修正方案：币种一律用币安合约清单（897 个）线上核对**，不靠 LLM 命名；
   - 另：现货单（如 `ATOMUSDT SPOT BUY`）要识别并提示"我们只做合约"。

4. **❗DeepSeek 余额耗尽**（Insufficient Balance）→ 解析链路全停，需先充值。

5. **❗真单执行层完全没写**
   - 目前只有"纸面计划"（dryRun），**没有 CCXT 真实下单、挂止损止盈单、移动止损、仓位状态管理**；
   - 需要：持仓状态机（币种/均价/数量/已平比例/止损/止盈）、真实滑点处理、失败重试、风控（最大 3 仓、单笔 300U 校验）。

6. **群选择/点击不稳定**：搜索打开群偶发失败（需滚动兜底）；5 群轮询一轮约 1~2 分钟。

7. **服务器脆弱**：2C4G，多个 Chromium 同时跑会内存打满卡死（曾多次发生）；**任何抓取都要单浏览器、及时清理进程**。

8. **未完成的验收**：实时链路只验证到"开单信号 → 纸面计划"，**"信号 → 真实下单 → 挂止盈止损 → 到期管理"整链未验证**。
