## 一、目标与硬性要求

**目标**：全自动加密合约跟单机器人 —— 自动盯飞书群 KOL 信号（**文字 + K线图**），
解析出「币种/方向/入场/加仓/止损/多档止盈」，在**币安 USDT-M 永续**下单并动态管理。

**硬性要求**：
1. 先 dryRun（纸面）跑通，用户点头才碰真钱
2. 数据必须真实可核验，**禁止编造**
3. 每一单都要看得懂（币种/开单时间/入场/止损/止盈/结单结果），**做成表格**
4. **只做 USDT 结尾的币种**（`XAUUSD` 是图表写法，币安上是 `XAUUSDT`）
5. 读图必须 100% 正确
6. **四档止盈只按三档做，第四档无视**
7. 信号可能是 1~3 条消息（文案/卡片/图）任意组合，必须合并
8. 通知含：币种/时间/金额/杠杆/止损位/止损点数(不含杠杆)/各档止盈/各档预期收益率（**含3倍杠杆**）
9. 博主发止盈通报时，回报用户自己的持仓
10. 代码更新及时上传 GitHub

## 三、交易执行规范（核心）

### 资金参数
| 项 | 值 |
|---|---|
| 单笔保证金 | **300 USDT** |
| 杠杆 | **3 倍** |
| 单笔名义 | 900 USDT |
| 最大同时持仓 | **5 笔** |
| 止盈档位 | **3 档**（第4档无视） |
| 测试模式 | 忽略 5 笔上限（仅测试期） |
| 轮询 | 0.5 秒 |
| 待合并窗口 | **4 秒** |

### 开仓价规则
比较博主点位与当前市价，差值 = (市价 − 博主价) / 博主价：

| 情形 | 动作 |
|---|---|
| 差值 **≤ 2%** | 直接市价、一次满仓 900U |
| **做多**且市价高于博主价 **>2%** | **不追高**：博主价×1.01 挂 150U + 博主价 挂 150U |
| **做空**且市价低于博主价 **>2%** | **不追空**：博主价×0.99 挂 150U + 博主价 挂 150U |
| 做多时市价低于博主价 / 做空时市价高于博主价 | 直接市价，止损不变 |

> 两笔各 150U 是**保证金**（×3 = 各 450U 名义，合计 900U 名义）。

### 区间信号
入场价 = 区间中点 `(A+B)/2`，小数部分**向上取整到该合约 tickSize**。

### 止损止盈
- **开仓全用市价**，**只有止盈止损用限价挂单**
- 止盈每档平 **1/3**
- **TP1 成交后止损立刻移到开仓价（保本损）**
- 止损/止盈**优先用 K 线图上读到的**（博主按图交易）

### 读图规则（必须 100% 正确）
- **红色横线 / 暗红区间 = 止损位**（在开仓价**下面**）
- **开仓价 = 止损上方第一个价格标签**
- **止盈 = 开仓价上方的实线横线**（不限颜色），只取前 3 档，第 4 档忽略
- 判定"是不是止盈线"用**横线像素覆盖率**：实线 ≈ 0.85~1.0；价格轴数字/当前价虚线/开仓标记 < 0.6

### 绝对底线
- **止损和止盈都没读到 → 只发「待确认」，绝不下单、绝不猜**
- 一切数值必须来自真实接口 / 真实图片

### 用户已明确不需要的
- **美股代币休市时不设禁止开单窗口** —— 休市时博主开仓照常跟进（已实测：休市盘口活跃、
  开盘跳空最大仅 0.034%，相对 2~5% 的止损距离可忽略）

## 五、已知的坑（别重复踩）

1. **群串台** → 必须每群独立标签页 + 标题匹配校验（`indexOf(群名) <= 3`）
2. **图表抓不到** → 图片惰性加载；只要消息里有图片元素就去 fetch，内容图等 6 秒
3. **重启会丢信号** → 开 5 个页面约 4.5 分钟，且启动游标直接跳到最新，停机期间的信号被跳过（未修复）
4. **通知文本不能列群名** → 否则被自己读到又解析一遍，自我循环
5. **启动时别写 `{"open": []}`** → 会清空已恢复的持仓
6. **`open_pos_ref` 与主循环 `open_pos` 必须同一个 dict** → 否则指令永远说"没有持仓"
7. **自建飞书应用进不了群** → 别在这上面浪费时间，用「网页自动化读群 + webhook 推送」
8. **PowerShell ↔ ssh 传中文/引号会被破坏** → 用 `scp` 传文件，不要在 ssh 命令里嵌中文
9. **本机 python.exe 是 WindowsApps 假壳** → Python 活全在服务器上干
10. **本机沙箱阻止 ssh 创建命名管道** → `git push` 需放宽权限重试
11. **别 grep 服务器上的大 JSON**（cookie/storage 文件）→ 一行几十 KB，输出会被撑爆
